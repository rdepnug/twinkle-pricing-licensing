## 退款、授权和「终身」承诺，条款里写死了什么

数码荔枝的购买须知是平台统一条款，有几条会直接影响你的钱包：

- 数字商品交付后一般不可退款，除非当地法律有强制要求，或该商品有单独的售后政策
- 多数商品提供免费试用，买前先试
- 「终身」「买断」「永久更新」这类说法以开发者提供的信息为准，后续更新、维护和策略调整由开发者负责，平台不承担补偿、退款或担保
- 授权禁止共享、转售或出借给第三方，违规后果由使用者承担
- 授权码丢失先联系开发者，联系不上再找平台协助

第三条最容易被忽略。买断买的是当下这个版本的使用权，「永久更新」能不能兑现，取决于开发者还在不在维护这个产品。这不是渠道方的问题，但付钱的人是你，把它当成风险项看待比较实际。
